Cycode is a complete Application Security Posture Management (ASPM) and software supply chain security platform that delivers visibility, security, and integrity across the entire software development lifecycle. Its Risk Intelligence Graph (RIG) correlates findings from SAST, SCA, secrets, IaC, and container scanning into a single risk model. Cycode exposes a REST API and webhooks, an official command-line interface (the `cycode` CLI for pip/Homebrew), and an official Model Context Protocol (MCP) server for AI-assisted scanning. Founded in 2019 and backed by Insight Partners, Cycode is certified SOC 2 Type II, ISO 27001, and CSA STAR Level 1. This profile was enriched by the API Evangelist pipeline.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Cycode: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
